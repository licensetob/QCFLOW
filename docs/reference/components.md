# 90+ 内置组件大全

在画布编辑器左侧的 **「组件物料库」** 中，平台提供了 **90+ 个开箱即用的内置组件**。你可以直接将它们拖入画布，并在右侧「属性检查器」中配置外观、绑定 `{{变量}}` 或编写交互事件。

---

## 一、页面骨架与导航组件（11 个）

用于搭建页面顶层框架、顶部/底部导航与页面间切换引导。

| 组件中文名 | 组件标识 (`type`) | 核心用途与常用配置 |
| :--- | :--- | :--- |
| **页面脚手架** | `system:scaffold` | 每个标准页面的最外层骨架容器，提供 `appBar`（顶部栏）、`body`（主体）、`bottomNavigationBar`（底部栏）、`floatingActionButton`（悬浮按钮）和 `drawer`（侧边抽屉）五大插槽。 |
| **滚动脚手架** | `system:scrollscaffold` | 自带纵向滚动与折叠头部效果的页面脚手架，适合长页面或个人中心页。 |
| **顶部导航栏** | `system:appbar` | 页面顶部标题栏，支持设置居中标题、左侧返回按钮、背景色与右侧操作图标。 |
| **底部导航栏** | `system:bottomnavbar` | App 底部多 Tab 切换栏，支持配置图标、标题、选中颜色与切换事件 (`onChanged`)。 |
| **标签栏** | `system:tab_bar` | 顶部或局部多标签切换条（如「全部 / 待付款 / 待发货」），支持横向滑动与下划线指示器。 |
| **侧边抽屉菜单** | `system:drawer_menu` | 从屏幕左侧滑出的抽屉导航菜单，放入 `Scaffold` 的 `drawer` 插槽，可通过 `打开左侧菜单()` 呼出。 |
| **面包屑导航** | `system:breadcrumb` | 多级路径层级导航（如 `首页 / 商品管理 / 编辑`），适合桌面端或管理后台页面。 |
| **分页器** | `system:pagination` | 页码切换控件（上一页、页码按钮、下一页），适合配合数据表格或后台分页列表使用。 |
| **索引栏** | `system:index_bar` | 通讯录/城市选择右侧 A-Z 字母快速定位索引条。 |
| **回到顶部** | `system:back_to_top` | 长列表滑动后浮现的一键回到顶部快捷按钮。 |
| **页面引用** | `system:page_ref` | 在当前页面中内嵌展示另一个「局部复用组件」页面，实现多页面公共区域复用。 |

## 二、布局容器组件（15 个）

用于控制子组件的排列方向、间距、对齐、层叠与响应式栅格排版。

| 组件中文名 | 组件标识 (`type`) | 核心用途与常用配置 |
| :--- | :--- | :--- |
| **纵向容器** | `system:column` | 子组件**从上到下垂直排列**。支持设置主轴/交叉轴对齐、`spacing`（子项间距）与开启滚动。 |
| **横向容器** | `system:row` | 子组件**从左到右水平排列**。适合图文并排、左右两端对齐（`spaceBetween`）。 |
| **层叠容器** | `system:stack` | 子组件**按图层前后叠加**。内部子组件可通过 `x`、`y` 坐标自由定位（如图片上叠加角标）。 |
| **通用容器** | `system:container` | 单子节点装饰容器，用于设置宽高、内外边距、背景色、渐变、圆角、边框与阴影。 |
| **横向滚动容器** | `system:h_scroll` | 允许内部多个子组件水平左右滑动（如横向商品推荐栏、分类图标栏）。 |
| **流式换行容器** | `system:wrap_layout` | 子组件水平排列，排满一行后**自动折行到下一行**（适合历史搜索词、商品规格标签）。 |
| **栅格行** | `system:grid_row` | 响应式多列栅格布局的「行」容器，内部搭配「栅格列 (`GridCol`)」使用。 |
| **栅格列** | `system:grid_col` | 放置在「栅格行」内部，可按份数（`span`）配置列宽占比。 |
| **轮播分页容器** | `system:page_view` | 支持全屏或局部左右滑动翻页的容器（如引导页、全屏短视频滑动）。 |
| **底部操作栏** | `system:bottom_action_bar` | 固定在页面底部的操作条（如商品详情页底部的「客服 / 购物车 / 立即购买」栏）。 |
| **底部抽屉面板** | `system:bottom_sheet_panel` | 从屏幕底部向上弹出的半屏/圆角抽屉面板容器。 |
| **间距盒** | `system:spacer_box` | 在两个组件之间插入固定宽高或弹性撑开的空白间距。 |
| **悬浮球** | `system:float_ball` | 悬浮在页面之上的可拖拽/可点击快捷悬浮球控件。 |

## 三、基础展示组件（20 个）

用于展示文字、图标、图片、状态反馈、步骤进度与动效数字。

| 组件中文名 | 组件标识 (`type`) | 核心用途与常用配置 |
| :--- | :--- | :--- |
| **文本** | `system:text` | 显示单行或多行文字。支持字号、粗细、颜色、对齐方式与 `{{变量}}` 插值绑定。 |
| **富文本** | `system:rich_text` | 在同一段文字中混排不同颜色、不同字号或可点击的高亮文字片段（如《用户协议》）。 |
| **图标** | `system:icon` | 展示内置 Material / Cupertino 矢量图标，支持调整图标尺寸与颜色。 |
| **图片** | `system:image` | 展示网络图片 URL 或本地资源图片，支持圆角裁剪与填充模式 (`fit`)。 |
| **头像** | `system:avatar` | 圆形或圆角方形用户头像，支持图片地址或文字首字母兜底展示。 |
| **徽标** | `system:badge` | 右上角小红点或未读消息数字角标（如购物车数量 `99+`）。 |
| **标签** | `system:chip` | 小巧的胶囊标签（如「官方自营」、「包邮」），支持配色、图标与删除关闭回调。 |
| **分割线** | `system:divider` | 水平或垂直分割细线，支持设置颜色、粗细与缩进间距。 |
| **进度条** | `system:progress` | 线性或环形进度指示器，绑定 `0 ~ 100`（或 `0.0 ~ 1.0`）进度数值。 |
| **轮播图** | `system:carousel` | 首页 Banner 广告图片轮播，支持自动播放、指示器圆点与点击跳转事件。 |
| **通告栏** | `system:notice_bar` | 顶部滚动公告条（带喇叭图标与跑马灯文字提示）。 |
| **倒计时** | `system:countdown` | 秒杀/活动倒计时展示（自动格式化显示 `天 : 时 : 分 : 秒`）。 |
| **数字滚动** | `system:animated_number` | 带有平滑翻牌/递增动画的数字展示控件（适合金额、实时看板大屏数字）。 |
| **步骤条** | `system:steps` | 展示流程进度（如「提交申请 -> 审核中 -> 审批通过」）。 |
| **时间轴** | `system:timeline` | 纵向时间节点列表（适合快递物流追踪、操作历史记录）。 |
| **折叠面板** | `system:expansion_panel` | 点击标题可展开/收起详细内容的手风琴面板（适合常见问题 FAQ）。 |
| **骨架屏** | `system:skeleton` | 数据加载完成前的灰色闪烁占位骨架块。 |
| **加载中** | `system:loading` | 旋转加载动画指示器，支持自定义加载提示文案。 |
| **空状态** | `system:empty_state` | 当列表无数据时展示的插画与引导提示（如「暂无订单」+ 重试按钮）。 |
| **结果状态** | `system:result_status` | 操作成功、失败或等待审核的整页/卡片状态反馈（带大图标、标题与操作按钮）。 |

## 四、表单与输入组件（21 个）

用于收集用户输入、搜索筛选、日期时间选择、文件上传与手写签名。

| 组件中文名 | 组件标识 (`type`) | 核心用途与常用配置 |
| :--- | :--- | :--- |
| **表单容器** | `system:form` | 包裹多个表单输入项，配合 `表单_校验()`、`表单_取值()`、`表单_重置()` 统一管理表单数据。 |
| **文本输入框** | `system:textfield` | 单行/多行文字输入、密码框、数字输入框。支持占位提示词、前后缀图标与 `onChanged` 事件。 |
| **搜索栏** | `system:search_bar` | 带放大镜图标与一键清空按钮的搜索输入框，支持回车搜索事件 (`onSubmitted`)。 |
| **开关** | `system:switch` | 开/关状态切换按钮，通过 `isChecked` 获取布尔状态。 |
| **开关组** | `system:switch_group` | 多项并排或纵向排列的开关组合。 |
| **复选框** | `system:checkbox` | 多选勾选框（如勾选「同意用户协议」）。 |
| **单选框** | `system:radio` | 单项选择圆点框。 |
| **选项组** | `system:choicegroup` | 支持单选或多选的胶囊/卡片式选项组（如选择商品尺码 `S / M / L / XL`）。 |
| **下拉选择框** | `system:dropdown` | 点击展开下拉菜单选择一项（如选择分类、城市）。 |
| **滑块** | `system:slider` | 拖动调节单一数值（如音量、亮度、字体大小）。 |
| **区间滑块** | `system:range_slider` | 双滑块拖动选择数值区间（如筛选价格区间 `￥100 ~ ￥500`）。 |
| **步进器** | `system:stepper_input` | 带 `-` 和 `+` 按钮的数量加减输入框（如购物车商品数量调节）。 |
| **评分组件** | `system:rating` | 五星好评/打分控件，支持半星与只读展示。 |
| **验证码输入** | `system:pin_input` | 4 位或 6 位独立方格短信验证码输入框，输入满自动触发完成事件。 |
| **标签输入框** | `system:tag_input` | 输入文字按回车即可生成多个胶囊标签的输入框。 |
| **日期选择器** | `system:date_picker` | 点击弹出日历选择年/月/日。 |
| **时间选择器** | `system:time_picker` | 点击弹出时钟选择时/分。 |
| **级联选择器** | `system:cascade_picker` | 多级联动选择器（如「省 / 市 / 区」三级联动或二级商品类目选择）。 |
| **颜色选择器** | `system:color_field` | 可视化取色表单项。 |
| **文件/图片上传** | `system:uploader` | 点击从相册或本地选择图片/文件并上传，支持预览已选图片网格。 |
| **手写签名板** | `system:signature_pad` | 支持手指或鼠标在画板上书写签名，支持清空重写与导出签名图片。 |

## 五、操作触发组件（5 个）

用于触发点击事件、页面跳转、表单提交或呼出快捷菜单。

| 组件中文名 | 组件标识 (`type`) | 核心用途与常用配置 |
| :--- | :--- | :--- |
| **按钮** | `system:button` | 标准交互按钮。支持实心填充 (`filled`)、描边 (`outlined`)、纯文字 (`text`) 三种样式，支持设置颜色、圆角与点击事件 (`onTap`)。 |
| **图标按钮** | `system:icon_button` | 纯图标点击按钮（如导航栏右上角的分享、设置、收藏按钮）。 |
| **悬浮按钮 (FAB)** | `system:fab` | 悬浮在页面右下角的圆形主操作按钮（如「+ 发帖」、「+ 新建」）。 |
| **悬浮展开菜单** | `system:fabmenu` | 点击右下角悬浮按钮后向上扇形/纵向展开多个快捷子操作按钮。 |
| **弹出菜单** | `system:popup_menu` | 点击后在按钮旁弹出下拉操作菜单项（如「编辑 / 分享 / 删除」）。 |

## 六、数据列表、卡片与图表组件（15 个）

用于绑定动态列表数据、展示电商/业务卡片以及渲染可视化统计图表。

| 组件中文名 | 组件标识 (`type`) | 核心用途与常用配置 |
| :--- | :--- | :--- |
| **列表视图** | `system:listview` | 高性能纵向滚动数据列表。设置 `dataSource` 绑定数组变量后，内部子组件可用 `{{item.字段}}` 渲染每一项。 |
| **网格视图** | `system:grid_view` | 多列二维网格列表（如 2 列商品矩阵、九宫格宫格菜单），支持配置列数 (`crossAxisCount`) 与间距。 |
| **瀑布流** | `system:waterfall_flow` | 双列或多列不等高交错瀑布流列表（适合图文社区、种草笔记流）。 |
| **分组列表** | `system:section_list` | 带吸顶分组标题头（Section Header）的列表（如按日期分组的账单明细、通讯录）。 |
| **下拉刷新容器** | `system:refresh_container` | 包裹在列表外层，提供下拉刷新 (`onRefresh`) 与触底加载更多能力。 |
| **卡片** | `system:card` | 带圆角、内边距与柔和阴影的通用内容卡片容器。 |
| **商品卡片** | `system:product_card` | 电商标准商品卡（内置商品主图、标题、副标题、价格、原价划线与购买按钮）。 |
| **价格标签** | `system:price_tag` | 自动格式化显示货币符号 `￥`、整数大字号与小数小字号的专业价格组件。 |
| **数据统计卡** | `system:stat_card` | 仪表盘核心指标卡（展示指标名称、大号核心数值、同比涨跌幅趋势图标）。 |
| **用户信息栏** | `system:user_info_bar` | 组合展示用户头像、昵称、认证徽章、简介与右侧关注按钮的复合组件。 |
| **数据表格** | `system:data_table` | 多列结构化数据表，支持表头配置、斑马纹、行选中与排序。 |
| **折线图** | `system:line_chart` | 可视化趋势折线图（适合展示营收趋势、访问量变化）。 |
| **柱状图** | `system:bar_chart` | 可视化对比柱状图（适合展示各品类销量、月度对比）。 |
| **饼图** | `system:pie_chart` | 可视化占比饼图/环形图（适合展示用户分布、支出占比）。 |

## 七、多媒体与逻辑功能组件（13 个）

提供音视频播放、扫码、二维码生成、Markdown 渲染及非视觉逻辑能力挂载。

| 组件中文名 | 组件标识 (`type`) | 核心用途与常用配置 |
| :--- | :--- | :--- |
| **大图查看器** | `system:image_viewer` | 支持双指缩放、平移查看高清大图。 |
| **二维码生成** | `system:qr_code` | 传入任意文本或网址 URL，实时生成可扫描的二维码图案。 |
| **条码/二维码扫描** | `system:barcode_scanner` | 调用设备摄像头扫描二维码或商品条形码，在回调事件中返回扫描结果字符串。 |
| **视频播放器** | `system:video_player` | 播放网络或本地视频流，内置播放/暂停、进度条与全屏切换控制栏。 |
| **音频播放条** | `system:audio_bar` | 紧凑型语音/音乐播放条，显示播放时长与波形进度。 |
| **Markdown 渲染器** | `system:markdown_view` | 将 Markdown 格式文本（如 AI 回复、帮助文档、富文本公告）直接渲染为精美排版。 |
| **内嵌网页 (WebView)** | `system:web_view` | 在应用内直接加载并浏览外部 H5 网页链接。 |
| **定时器组件** | `system:timer` | 按设定间隔毫秒数周期性触发回调事件（适合轮询状态、定时刷新）。 |
| **接口请求组件** | `system:api` | 声明式挂载网络接口请求，支持进入页面自动拉取并绑定状态。 |
| **本地存储组件** | `system:storage` | 声明式读写本地持久化键值数据。 |
| **事件总线组件** | `system:event_bus` | 跨页面、跨局部组件广播与监听自定义消息事件。 |
| **权限认证组件** | `system:auth` | 登录态守卫与角色权限显隐控制。 |
| **日志组件** | `system:logger` | 页面级关键行为与埋点日志记录。 |
