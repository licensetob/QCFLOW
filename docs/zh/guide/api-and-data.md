# 接口配置与列表数据绑定

在实际应用中，页面数据通常来自后端服务器接口。本章将手把手教你如何在 **「API 接口中枢」** 配置接口，并用几行中文代码将接口数据绑定到画布的列表、网格、卡片和详情页上。

---

## 一、在 API 接口中枢配置后端服务

1. 点击画布顶部工具栏的 **「API 中枢」** 按钮，打开接口管理工作台。
2. **配置服务通道（Base URL）**：
   - 设置默认后端通道的基础地址（例如：`http://127.0.0.1:8080` 或线上域名 `https://api.example.com`）。
   - 如果使用 AI 全栈助手生成了本地后端，系统会**自动分配可用端口并同步写入该通道地址**，无需手动填写。
3. **添加接口定义**：
   - 点击 **「+ 新增接口」**，填写：
     - **接口中文别名**（如 `宠物列表`、`提交领养申请`）——填写后即可在代码中用 `#宠物列表` 直接调用！
     - **请求路径**（如 `/api/pets`、`/api/adopt`）
     - **请求方式**（`GET` / `POST` / `PUT` / `DELETE`）
     - **默认请求头或示例参数**（支持在面板中直接点击「发送测试」查看接口返回的真实 JSON 报文）。

---

## 二、发起网络请求的三种常用写法

根据后端接口返回的数据结构（列表、单条详情或提交表单），你可以选用最趁手的中文网络函数：

### 场景 1：拉取列表数据（自动解包）

后端接口经常把列表包在 `{"code": 200, "data": {"items": [...]}}` 或 `{"data": [...]}` 等不同格式的信封里。使用 **`网络_请求列表`** 或 **`网络_解包列表`**，平台会自动剥离外层信封，直接为你提取出干净的数组列表：

```dart
变量 宠物列表 = []

函数 页面加载完成() {
  // 直接请求并自动解包为列表，支持传入查询参数
  宠物列表 = 网络_请求列表(#宠物列表, 参数: {
    "page": 1,
    "category": "猫咪"
  })
}
```

### 场景 2：拉取单条详情或统计卡片数据

当接口返回的是单个对象（如个人中心信息、商品详情、首页统计数据 `{"total": 128, "rescuingCount": 15}`）时，使用 **`网络_请求详情`** 或 **`网络_解包字典`**：

```dart
变量 统计信息 = {}

函数 页面加载完成() {
  统计信息 = 网络_请求详情("/api/stats")
}
```

### 场景 3：提交表单数据（POST 请求）

```dart
函数 提交申请() {
  // 校验手机号
  如果 (!校验_是否为手机号(inputPhone.text)) {
    系统_弹出错误提示("请填写正确的手机号")
    返回
  }

  系统_显示加载提示("正在提交...")
  变量 响应 = 网络_POST("/api/adopt", 数据: {
    "petId": 当前宠物ID,
    "applicant": inputName.text,
    "phone": inputPhone.text
  })
  系统_隐藏加载提示()

  系统_弹出成功提示("申请提交成功！")
  系统_返回页面()
}
```

## 三、把接口数据绑定到画布组件上

### 1. 绑定到列表视图 / 网格视图 / 瀑布流

1. 从左侧物料库拖入一个 **「列表视图 (ListView)」**（或 **「网格视图 (GridView)」** / **「瀑布流 (WaterfallFlow)」**）。
2. 选中该列表组件，在右侧属性面板找到 **「数据源 (dataSource)」**，填入刚才定义的页面变量：
   ```text
   {{宠物列表}}
   ```
3. 往列表内部拖入子组件（如「商品卡片 ProductCard」或「容器 + 图片 + 文本」），在子组件的属性中使用 **`{{item.字段名}}`** 绑定每一项的字段：
   - 图片组件 `url` 属性填入：`{{item.avatar}}`
   - 标题文本 `text` 属性填入：`{{item.name}}`
   - 副标题文本 `text` 属性填入：`品种：{{item.breed}} · 年龄：{{item.age}}`

### 2. 结合「下拉刷新容器」实现下拉刷新与分页

如果你希望列表支持手指下拉刷新：
1. 在列表外层包裹一个 **「下拉刷新容器 (RefreshContainer)」**。
2. 在右侧「事件」面板为它的 **「刷新事件 (onRefresh)」** 绑定重新拉取数据的代码，拉取完成后界面会自动收起刷新动画。

## 四、页面跳转传参与登录 Token 管理

### 1. 点击列表项跳转到详情页并传参

在列表项的点击事件中，使用 `系统_跳转页面` 将当前项的 `id` 传给详情页：

```dart
// 跳转到详情页，并携带参数
系统_跳转页面(#宠物详情页, 参数: {
  "id": item.id,
  "title": item.name
})
```

### 2. 登录 Token 与本地缓存持久化

登录成功后，只需调用一次 **`网络_设置Token`**，后续所有的网络请求都会自动在请求头（Authorization）中携带该 Token，同时你可以用 **`系统_保存本地`** 将用户信息持久化保存在设备本地（基于高性能加密存储，App 重启后依然有效）：

```dart
函数 登录() {
  变量 结果 = 网络_POST("/api/login", 数据: {
    "username": inputUser.text,
    "password": 编码_MD5(inputPwd.text)
  })

  变量 token = 字典_取值(结果, "token")
  如果 (文本_是否不为空(token)) {
    // 1. 设置全局网络请求 Token
    网络_设置Token(token)
    // 2. 持久化保存到本地设备
    系统_保存本地("user_token", token)
    系统_保存本地("user_profile", 字典_取值(结果, "user"))
    // 3. 关闭登录页并进入主页
    系统_关闭所有并跳转(#主页)
  }
}
```
