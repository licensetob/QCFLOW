# 平台简介与界面速览

**QC Flutter Flow** 是一款面向多端应用研发的**可视化低代码与 AI 全栈协同开发平台**。你无需手动配置繁琐的跨平台开发环境，也不必死记硬背复杂的底层语法，即可通过**「拖拽搭界面 + 中文写逻辑 + AI 对话生成」**的方式，快速开发出可运行在 **Android、iOS、Windows、macOS、Linux 与 Web** 上的原生级应用。

---

## 核心能力一览

| 核心能力 | 你能用它做什么 |
| :--- | :--- |
| **🎨 可视化拖拽画布** | 提供 **90+ 内置组件**与 **24 种布局容器**，支持自由拖拽、对齐吸附、手机/平板/桌面三端断点实时预览。 |
| **🀄 中文逻辑编排 (DSL)** | 内置 **142 个中文函数**（涵盖弹窗、路由跳转、网络请求、文本/数组/字典/时间处理、表单校验、加密编码），支持 `#颜色` 与 `#接口名` 快捷输入，配合 9 级智能联想补全，像写中文句子一样写业务逻辑。 |
| **🤖 AI 全栈协同助手** | 用自然语言描述需求，AI 可直接为你**生成多页面前端界面 + 配套后端接口服务**；也支持针对当前页面的 **UI 局部微调**与**报错一键修复**。 |
| **🌐 接口中枢与数据绑定** | 在可视化面板中统一管理后端接口通道，通过 `{{变量名}}` 将接口数据直接绑定到列表、卡片、图表与文本组件上。 |
| **🧩 自定义组件工作台** | 内置独立的组件开发工具，支持自定义组件属性、事件、方法与画布预览外观，并可一键发布到画布物料库或组件商城。 |
| **📦 一键环境配置与多端打包** | 内置免安装便携式开发环境（自动安装 Flutter / Java / Android 工具链与国内镜像测速），自动扫描组件所需的手机权限，支持一键生成安卓签名证书并导出 APK / 安装包或标准 Flutter 源码工程。 |

## 工作台主界面速览

打开 **QC Flutter Flow** 后，主工作台分为两大区域：**主控管理台** 与 **应用画布编辑器**。

### 1. 主控管理台（左侧导航）

在进入具体项目前，你可以通过主控台管理你的所有研发资产：

- **项目管理**：新建空白项目、从模板创建项目、导入/导出项目工程，或管理已有应用。
- **环境管理**：一键体检当前电脑的开发工具链状态（Flutter SDK、Java JDK、Android SDK、Git），支持一键下载安装与国内镜像源自动测速切换。
- **组件开发**：进入独立的自定义组件研发工作台，制作并测试专属业务组件。
- **组件商城**：浏览、下载团队或社区共享的封装组件，一键导入到自己的项目中使用。
- **系统设置**：切换工作台浅色/深色主题、界面字体（MiSans / 苹方 / 鸿蒙字体）、AI 模型密钥与账号信息。

---

### 2. 应用画布编辑器（核心创作区）

双击打开任意项目后，即进入核心的**可视化画布编辑器**，界面由五个核心区域组成：

```
+-----------------------------------------------------------------------------------+
| 顶部工具栏：项目切换 | 手机/平板/桌面断点 | 缩放比例 | 撤销/重做 | API中枢 | 原生配置 | ⚡运行 |
+------------------+---------------------------------------------+------------------+
| 左侧面板          |                                             | 右侧面板          |
|                  |                                             |                  |
| [页面与路由树]    |              中间可视化设计画布               | [四象限属性检查器] |
| - 启动组/业务组   |         （所见即所得拖拽 · 多断点预览）        | - 外观 (宽高/色)  |
| - 局部复用组件    |                                             | - 内容 (文案/图)  |
|                  |                                             | - 事件 (点击/改)  |
| [90+ 组件物料库]  +---------------------------------------------+ - 布局 (对齐/距)  |
| - 骨架 / 导航     | 底部多功能工作台（可折叠切换）                 |                  |
| - 布局 / 基础     | [中文 DSL 代码编辑器]  |  [语法诊断]  | [运行控制台日志] | [🤖 AI 助手面板]  |
| - 表单 / 数据     | （智能联想补全 · 与画布双向实时同步）          | （对话生成与微调） |
+------------------+---------------------------------------------+------------------+
```

1. **顶部工具栏**：
   - 切换画布设备视口（**手机** `375×812` / **平板** `768×1024` / **桌面** `1440×900`）。
   - 调整画布缩放比例（`25% ~ 400%`）、执行撤销（`Undo`）与重做（`Redo`）。
   - 打开 **API 接口中枢**、**项目原生配置（权限/图标/签名）**。
   - 选择目标设备（真机/模拟器/桌面端），点击 **「运行」**、**「⚡ 热重载」** 或 **「构建发布」**。
2. **左侧面板（页面树 + 组件物料库 + 组件层级树）**：
   - **页面管理**：按业务分组管理所有页面与局部复用组件，系统会根据分组自动生成页面路由。
   - **物料库**：按分类浏览或搜索 90+ 内置组件，直接用鼠标拖入画布即可添加。
   - **组件树**：以树状结构查看当前页面的所有组件嵌套关系，点击即可在画布中定位并居中高亮。
3. **中间主画布**：
   - 所见即所得的交互设计区。支持鼠标拖拽排版、拉伸尺寸、框选多选、右键快捷菜单（复制、删除、包裹容器）。
4. **右侧面板（四象限属性检查器 / AI 智能助手）**：
   - 选中任意组件时，右侧展示 **外观、内容、事件、布局** 四大属性配置面板。
   - 切换到 **AI 助手** 标签页，可用自然语言让 AI 创建页面、生成后端或调整当前界面。
5. **底部面板（中文 DSL 逻辑编辑器 + 实时诊断 + 运行日志）**：
   - 在这里编写页面的状态变量、生命周期函数与组件事件代码。你在画布上绑定的事件与这里的代码**双向实时同步**，且支持错误行号实时提示。
