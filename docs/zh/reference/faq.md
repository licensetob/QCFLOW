# 快捷键与常见问题排查 (FAQ)

本页汇总了 QC Flutter Flow 画布与代码编辑器的高频快捷键，以及日常使用中最常见问题的解决方法。

## 二、常见问题与排查方法

### Q1：第一次点击「运行」时，下载依赖比较慢或者卡住怎么办？
- **原因**：首次运行需要拉取基础依赖包，若网络直连海外源较慢会影响速度。
- **解决办法**：
  1. 打开主控台左侧的 **「环境管理」**，点击 **「镜像测速」**，系统会自动测试并切换到延迟最低的国内镜像源（阿里云、腾讯云或清华源）。
  2. 一旦首次运行成功，后续所有项目都会默认启用 **离线优先模式（`--offline`）**，直接复用本地缓存，秒级完成依赖解析。
  3. 如果你的电脑开启了系统代理（VPN），平台沙盒会自动识别并穿透代理；若某个进程异常卡住，点击顶部 **「⏹ 终止运行」** 即可一键清理全部后台子进程。

---

### Q2：在画布上调组件宽高时，突然出现红色报错卡片怎么办？
- **原因**：在横向容器（`Row`）或纵向容器（`Column`）中，给子组件设置了互相冲突的无限宽高约束（例如在未限定高度的滚动容器里又放了一个无限高度的列表）。
- **解决办法**：
  - **无需重启软件**！画布已经自动拦截了该渲染异常，你只需要直接点击红色错误卡片上的 **「一键撤销上一步 (Undo)」** 按钮（或按 `Ctrl/Cmd + Z`），画布就会立即回退到报错前的正常状态。
  - 若发生严重布局死锁，系统还会在 **2 秒后自动为你触发回滚**，保护你的页面数据不丢失。

---

### Q3：为什么我的列表视图（`ListView`）绑定了接口数据却显示空白？
请按以下三步检查：
1. **检查列表数据源绑定格式**：选中画布上的 `ListView`，查看右侧属性面板的 `dataSource` 是否填入了带双花括号的变量名，例如 `{{宠物列表}}`（不要只填 `宠物列表`）。
2. **检查接口返回值是否已解包**：如果后端返回的 JSON 是 `{"code": 200, "data": [...]}`，直接用 `网络_GET` 拿到的是外层字典而不是列表。请改用 **`网络_请求列表(#接口名)`** 或用 **`网络_解包列表(响应)`**，它会自动帮你把里面的数组提取出来。
3. **检查列表高度约束**：如果 `ListView` 被放在一个普通 `Column`（纵向容器）里面，请给 `ListView` 设置一个具体的高度（如 `400`），或者将外层容器替换为页面主体的根列表。

### Q4：我在底部代码编辑器里自己写的函数，再去画布拖拽组件会被覆盖冲掉吗？
- **绝对不会**。平台采用双向无损增量合并技术：你在画布上拖拽组件、修改属性，只会更新对应组件的布局与事件绑定；你在代码编辑器里自己定义的**状态变量、自定义辅助函数以及注释都会被 100% 保留**。

---

### Q5：如何让平板端和电脑桌面端显示跟手机端不一样的宽度和排版？
1. 在画布顶部工具栏点击切换视口图标，从 **「手机 (`375×812`)」** 切换到 **「平板 (`768×1024`)」** 或 **「桌面 (`1440×900`)」**。
2. 在切换后的视口下直接修改组件的宽高、边距、背景色或圆角。
3. 这些样式会自动保存为该断点的专属覆盖样式，手机端原有的排版完全不受影响。

---

### Q6：我想让 AI 帮我改一下按钮颜色，它会不会把我的后端服务重新生成一遍？
- **不会**。AI 助手内置了意图分级快车道：当你只是要求调整 UI 样式、修改组件布局或修复某行代码语法时，AI 会自动走 **L1 局部修改快车道**，几秒钟内直接更新当前画布，不会触碰或重启你已有的后端服务与测试数据。

---

### Q7：应用做好了，怎么打包发给别人安装到手机上？
1. 点击画布右上角的 **「项目原生配置」**：
   - 检查应用名称与包名；
   - 在「权限管理」点击 **「一键添加推荐权限」**；
   - 在「签名配置」点击 **「生成全新 Keystore 证书」**，填好密码一键生成签名。
2. 点击顶部工具栏的 **「构建发布」 -> 「导出 Android APK」**，构建完成后即可直接将生成的 `.apk` 安装包发送到手机安装使用！
