# 中文逻辑编排（DSL 教程）

在 QC Flutter Flow 中，你不需要掌握复杂的原生编程语法，就可以用**中文变量、中文控制流和 142 个中文内置函数**编写出完整的页面交互与业务逻辑。

点击画布底部展开 **「逻辑编排（代码编辑器）」**，或者在右侧组件属性面板点击任意事件旁边的 **「编辑代码」**，即可开始编写。

---

## 一、定义变量与状态绑定

页面中的变量分为两类：**页面状态变量**（定义在函数外部，修改后会自动刷新绑定的界面组件）与**局部变量**（定义在函数内部，仅在当前函数执行时有效）。

### 1. 声明页面状态变量

在页面代码顶部使用 `变量` 关键字定义状态变量：

```dart
// 基础类型变量
变量 用户名 = "访客"
变量 商品数量 = 1
变量 是否已收藏 = false

// 列表与字典变量
变量 标签列表 = ["热门", "新品", "限时折扣"]
变量 订单详情 = {
  "订单号": "QC20261014",
  "金额": 99.5,
  "状态": "已支付"
}
```

### 2. 在画布组件上绑定变量（`{{变量名}}`）

定义好页面变量后，你可以在画布任意组件的右侧属性面板中使用 **`{{ }}`** 语法绑定它：

| 绑定场景 | 属性面板填写内容 | 实际运行效果 |
| :--- | :--- | :--- |
| **直接显示变量值** | `{{用户名}}` | 当代码中修改 `用户名 = "张三"` 时，文本自动刷新为 `张三` |
| **文字拼接插值** | `已选 {{商品数量}} 件，合计 ￥{{订单详情.金额}}` | 自动将变量嵌入文字中间并实时更新 |
| **控制组件显示/隐藏** | 在 `visible` 属性填入 `{{是否已收藏}}` | 当 `是否已收藏` 为 `true` 时显示该组件，为 `false` 时自动隐藏 |
| **绑定列表数据源** | 在列表视图的 `dataSource` 填入 `{{标签列表}}` | 根据列表长度自动循环渲染每一项 |

## 二、操控画布上的组件

画布上的每一个组件都有一个唯一的 **组件 ID**（例如按钮 `btnSubmit`、文本 `txtTitle`、输入框 `inputPhone`、开关 `switchDark`）。你可以在代码中直接通过组件 ID 读取它的值，或调用 `set*` 方法修改它的外观：

```dart
// 1. 读取输入框或开关的当前状态
变量 手机号 = inputPhone.text
变量 开启通知 = switchNotify.isChecked

// 2. 动态修改组件的文字、颜色、禁用状态
txtTitle.setText("欢迎回来，" + 手机号)
txtTitle.setTextColor(#10B981)
btnSubmit.setLabel("已提交")
btnSubmit.setDisabled(true)
```

## 三、`#` 快捷语法糖（颜色、接口与常量）

为了让你写代码更快，编辑器内置了强大的 **`#` 符号快捷识别**：

1. **直接写十六进制颜色**：
   无需转换颜色格式，直接写 `#FF6B00`、`#2563EB` 或 `#FFF`，系统会自动识别为颜色对象：
   ```dart
   btnSubmit.setColor(#FF6B00)
   ```
2. **快速引用接口端点与请求方式**：
   输入 `#` 会自动弹出当前项目配置的所有 API 接口名称与常用常量：
   ```dart
   // #宠物列表、#GET、#POST、#空（代表 null）
   变量 结果 = 网络_接口请求(#宠物列表, 请求方式: #GET)
   如果 (结果 != #空) {
     系统_弹出成功提示("加载成功")
   }
   ```

## 四、条件判断与循环控制流

编辑器完全支持中文结构化控制流关键字（输入关键字后按 `Tab` 可自动展开代码大括号）：

### 1. 条件判断（`如果 / 否则`）

```dart
变量 手机号 = inputPhone.text

如果 (文本_是否为空(手机号)) {
  系统_弹出错误提示("手机号不能为空")
  返回
} 否则 如果 (!校验_是否为手机号(手机号)) {
  系统_弹出错误提示("请输入正确的 11 位手机号")
  返回
} 否则 {
  系统_弹出成功提示("校验通过！")
}
```

### 2. 遍历与循环（`遍历 / 循环`）

```dart
// 计算购物车商品总价
变量 总价 = 0.0
遍历 (商品 在 购物车列表) {
  总价 = 总价 + 字典_取值(商品, "单价")
}
系统_调试输出("当前总价：" + 转文本(总价))
```

> 💡 **更简单的写法**：对于列表字段求和，你也可以直接调用内置函数：`变量 总价 = 数组_字段求和(购物车列表, "单价")`。

## 五、页面生命周期函数

如果你希望在**刚打开页面时自动请求接口加载数据**，只需在页面代码中编写 `页面加载完成` 函数：

```dart
变量 商品列表 = []

// 进入页面时自动触发执行
函数 页面加载完成() {
  加载商品数据()
}

// 你自己封装的页面辅助函数
函数 加载商品数据() {
  系统_显示加载提示("正在加载商品...")
  变量 响应 = 网络_请求列表(#获取商品列表)
  商品列表 = 响应
  系统_隐藏加载提示()
}
```

> **双向无损同步保障**：你在代码编辑器里自己写的辅助函数（如上面的 `加载商品数据()`）、顶部变量声明和注释，在画布拖拽或修改组件属性时**会被 100% 完整保留，绝不会被覆盖丢失**。

## 六、智能联想补全与实时语法诊断

1. **9 级优先级智能联想**：
   当你在编辑器中输入任意中文或字母时，会立即弹出候选菜单，并按你的使用频率智能排序：
   - **第 1 梯队**：当前事件的参数与局部变量（如 `item`、`index`）
   - **第 2 梯队**：当前页面的状态变量（如 `商品列表`、`用户名`）
   - **第 3 梯队**：全局变量与当前画布上的组件 ID（如 `inputPhone`、`btnSubmit`）
   - **第 4 梯队**：中文控制流关键字、`#` 接口名称与 **142 个中文标准函数**
2. **多行书写免分号**：
   你可以不写行尾分号 `;`，也可以把较长的函数参数、列表或字典拆成多行书写，编辑器会自动识别括号层级，不会产生断行报错。
3. **50 毫秒实时错误诊断**：
   如果括号未闭合或函数名拼写错误，底部「诊断面板」会实时标出具体的**错误行号与中文修复建议**，点击即可直接跳转到对应代码行。
