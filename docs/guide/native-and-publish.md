# 原生权限配置、真机调试与打包发布

当你的应用页面与交互逻辑开发完成后，你可以通过 QC Flutter Flow 内置的 **「原生配置中枢」** 与 **「离线优先构建沙盒」**，无需手工编写复杂的各端原生配置文件，即可完成权限配置、签名打包与多端发布。

---

## 一、项目原生配置中枢

点击画布顶部工具栏右上角的 **「项目原生配置」** 按钮，即可在一个弹窗中统一管理 **Android、iOS 与 macOS** 各端的工程配置：

### 1. 基础应用信息
- **应用显示名称 (App Name)**：安装在手机桌面或电脑窗口顶部显示的名称。
- **应用包名 (Package Name / Bundle ID)**：如 `com.company.myapp`，自动同步到 Android 与 iOS 工程。
- **版本号 (Version Name & Build Number)**：如 `1.0.0+1`。

### 2. 组件权限智能感知与一键添加
很多新手在打包手机 App 时最头疼的就是“加了扫码或定位组件，结果真机运行闪退，因为忘了配 Android 权限或 iOS 隐私说明文案”。

在 QC Flutter Flow 中，系统会**自动扫描你当前画布上用到的所有组件**，并列出推荐的原生权限清单：

| 当你在画布中使用了... | 系统自动识别并推荐添加的 Android 权限 | 系统自动生成的 iOS 隐私描述 (`Info.plist`) |
| :--- | :--- | :--- |
| **条码/二维码扫描 (`BarcodeScanner`)** | `CAMERA`、`FLASHLIGHT` | `NSCameraUsageDescription`（用于扫描条形码与二维码） |
| **地图/定位组件** | `ACCESS_FINE_LOCATION`、`ACCESS_COARSE_LOCATION` | `NSLocationWhenInUseUsageDescription`（用于展示地图与定位） |
| **手写签名板 (`SignaturePad`) / 文件上传 (`Uploader`)** | 存储与媒体读取权限 | `NSPhotoLibraryAddUsageDescription`（用于保存或选择相册图片） |

**操作方式**：
1. 打开「权限管理」标签页，查看顶部高亮的 **「组件自动推荐权限列表」**。
2. 点击 **「一键添加推荐权限」**，也可根据需要手动勾选添加网络、麦克风、蓝牙、通知等其它权限。

### 3. 第三方 SDK 密钥管理
如果项目中使用了地图、支付或推送服务，可在 **「第三方密钥」** 标签页直接填入对应的 Android / iOS API Key，系统会自动注入到各端原生配置中。

### 4. 变更对比预览（Diff）与安全落盘
点击 **「保存与应用」** 前，系统会弹出 **「变更对比预览 (Unified Diff)」** 窗口：
- 用**绿色高亮**展示将在 `AndroidManifest.xml`、`build.gradle`、`Info.plist` 等文件中新增的配置行；
- 确认无误后点击 **「确认应用」**，才会原子化安全写入磁盘，杜绝误改破坏工程。

## 二、Android 签名证书一键生成

发布正式版 Android 安装包（APK / AAB）需要签名证书（`.jks`）。你不需要打开终端去敲复杂的 `keytool` 命令：

1. 在「项目原生配置」中切换到 **「签名配置」**（或点击构建菜单中的「APK 签名工具」）。
2. 选择 **「生成全新 Keystore 证书」**，依次填入：
   - **证书文件名**（默认 `release.jks`）
   - **密钥别名 (Key Alias)**
   - **密钥库密码与别名密码**
   - **开发者/组织名称与有效期（年）**
3. 点击 **「一键生成并绑定」**，系统会自动生成证书文件，并将签名配置自动写入 Android 构建脚本中。

## 三、真机调试与秒级热重载

1. **连接设备**：
   - **桌面端调试**：直接选择 `Windows` 或 `macOS` 桌面设备，最快验证业务逻辑。
   - **手机真机调试**：用数据线连接开启了「USB 调试」的 Android 手机（或 iOS 设备），顶部设备下拉框会自动识别并列出你的手机型号。
   - **模拟器调试**：点击设备下拉框旁的「新建/启动模拟器」，可直接创建或拉起本地模拟器。
2. **一键运行（离线优先加速）**：
   - 点击顶部绿色 **「▶ 运行」** 按钮。
   - 平台优先采用本地离线依赖缓存（`--offline`），相比传统每次联网检查依赖提速 **80% 以上**；同时自动继承系统网络代理并设置 10 分钟超时护栏，防止进程卡死。
3. **实时日志与热重载**：
   - 在底部 **「运行日志」** 面板查看应用输出与调试日志（配合 `系统_调试输出()` 或 `系统_打印日志()` 使用）。
   - 修改画布样式或代码后，点击 **「⚡ 热重载」** 即可在 1 秒内刷新真机画面；点击 **「⏹ 终止运行」** 会彻底清理所有后台构建子进程，不留僵尸进程占用端口。

## 四、打包导出多端安装包与纯净源码

点击顶部工具栏的 **「构建发布」**，你可以选择两种交付形态：

1. **直接导出各平台安装包**：
   - **Android**：导出已签名的 `.apk` 安装包或上架 Google Play 的 `.aab` 包。
   - **iOS**：导出 iOS 工程与 `.ipa` 归档包（需在 macOS 环境下配合 Xcode 签名）。
   - **桌面端与 Web**：一键打包生成 Windows 可执行程序、macOS `.app` 应用或 Web 静态站点。
2. **导出 100% 纯净标准 Flutter 源码工程**：
   - 平台生成的所有页面、路由、主题配置与控制器均为**标准、可读性极高的原生 Dart / Flutter 源码**，无任何专有黑盒锁定。
   - 你可以随时将完整工程目录复制到 VS Code 或 Android Studio 中进行二次深度开发或接入企业现有 CI/CD 流水线。
