# 可视化画布与页面管理

本章详细介绍如何在 QC Flutter Flow 中管理多页面应用结构、使用可视化画布进行精准排版、适配手机/平板/桌面多端屏幕，以及配置组件的四象限属性。

---

## 一、页面与分组管理

在左侧面板点击 **「页面」** 图标，即可管理整个应用的所有页面、路由分组与局部复用组件。

### 1. 页面分组与自动路由

平台采用 **「分组 + 页面」** 的两级管理模式，无需手动编写复杂的路由表配置文件：

| 分组类型 | 默认标识 | 用途说明 | 自动生成的路由路径示例 |
| :--- | :--- | :--- | :--- |
| **启动组** | `group_startup` | 存放应用启动页或主框架页 | `/startup/main` |
| **业务分组** | 自定义（如 `user`、`shop`） | 按业务模块归类页面（如登录注册、商品模块） | `/user/login`、`/shop/detail` |
| **局部组件组** | `group_local` | 存放可在多个页面复用的局部组件（如商品卡片、自定义弹窗） | 不生成独立路由，供页面引用或弹窗调用 |
| **全局配置** | `group_global_config` | 管理全局状态变量、全局主题色与网络通道配置 | 全局生效 |

### 2. 页面常用操作

- **新建分组**：点击页面面板顶部的 **「+ 新建分组」**，输入分组名称（如 `订单模块`）。
- **新建页面**：点击目标分组右侧的 **「+」** 号，可选择创建：
  - **空白页面**：带标准页面脚手架（Scaffold）的全新页面。
  - **预设模板页**：从内置行业模板快速创建。
  - **局部复用组件**：创建独立的局部组件画板，可在其它页面通过「页面引用」组件嵌入，或通过 `系统_弹出组件("组件名")` 弹窗展示。
- **复制页面**：在任意页面条目上点击鼠标右键 -> 选择 **「复制页面」**，系统会完整克隆该页面的组件树与交互代码。
- **删除页面保护**：右键选择 **「删除」** 可移除页面。平台内置了防死锁保护机制——不允许删光所有业务页面，确保工程始终保有至少一个可启动的主页面。

## 二、画布排版与容器插槽用法

### 1. 页面脚手架（Scaffold）的五大插槽

每个标准页面最外层都是一个 **「页面脚手架 (Scaffold)」**，它提供了 5 个专属插槽区域。将组件拖入对应区域即可自动完成页面结构装配：

- **`appBar`（顶部导航栏插槽）**：放置「顶部导航栏 (AppBar)」或「搜索栏 (SearchBar)」。
- **`body`（页面主体插槽）**：放置页面核心内容（通常先放入一个 `纵向容器 Column`、`列表视图 ListView` 或 `下拉刷新容器 RefreshContainer`）。
- **`bottomNavigationBar`（底部栏插槽）**：放置「底部导航栏 (BottomNavBar)」或电商详情页常用的「底部操作栏 (BottomActionBar)」。
- **`floatingActionButton`（悬浮按钮插槽）**：放置右下角「悬浮按钮 (FAB)」或「悬浮菜单 (FabMenu)」。
- **`drawer`（侧边抽屉插槽）**：放置「侧边抽屉菜单 (DrawerMenu)」，可通过 `打开左侧菜单()` 函数呼出。

### 2. 常用布局容器选择指南

在画布中排版时，合理组合容器可以实现任意复杂的界面布局：

| 你想实现的排版效果 | 推荐使用的容器组件 | 使用技巧 |
| :--- | :--- | :--- |
| **从上到下垂直排列** | **纵向容器 (`Column`)** | 在右侧「布局」面板设置 `spacing`（子项间距）和对齐方式；若内容超出一屏，可在属性中开启滚动模式。 |
| **从左到右水平排列** | **横向容器 (`Row`)** | 适合做图文并排、左右两端对齐（将主轴对齐设为 `spaceBetween`）。 |
| **多个元素重叠（如图片上叠文字角标）** | **层叠容器 (`Stack`)** | 子组件可以直接在画布上拖拽位置（调整 `x`、`y` 坐标）实现多层叠加。 |
| **加背景色、圆角、边框、阴影或内边距** | **通用容器 (`Container`)** / **卡片 (`Card`)** | 单子节点容器，专门用来做视觉装饰、留白间距或固定宽高。 |
| **横向滑动标签或商品栏** | **横向滚动 (`HScroll`)** | 内部放入多个卡片或标签即可直接左右滑动。 |
| **自动换行的标签组/热搜词** | **流式换行 (`WrapLayout`)** | 子项排满一行后自动折行到下一行。 |
| **响应式多列网格布局** | **栅格行 (`GridRow`) + 栅格列 (`GridCol`)** | 按栅格比例分配列宽，适合仪表盘与后台表单排版。 |

### 3. 组件树定位与画布操作技巧

- **组件树自动居中定位**：当页面组件层级较深、在画布上不好点选时，直接在左侧 **「组件树」** 面板点击节点名称，或者在画布点击组件，左侧组件树都会自动展开并平滑滚动到视口正中央。
- **框选与编组**：按住 `Shift` 键在画布上拖拽框选多个同级组件，点击鼠标右键选择 **「组合为容器 (Row / Column / Container)」**，即可一键将它们打包进同一个父容器中。
- **实时尺寸拉伸**：选中画布上的组件后，拖拽蓝色高亮框四周的控制手柄即可直观调整宽高。
- **画布异常一键恢复**：如果不小心设置了冲突的宽高约束导致组件渲染报错，画布不会崩溃卡死，而是会显示一张友好的异常提示卡，点击卡片上的 **「一键撤销上一步」** 即可立即恢复正常。

## 三、多端响应式断点设计

同一个页面如何同时适配手机、平板和电脑大屏？QC Flutter Flow 支持**三端断点独立样式覆盖**：

1. 在顶部工具栏点击切换视口断点：
   - **📱 手机端 (Mobile)**：`375 × 812`（默认基准视口）
   - **📟 平板端 (Tablet)**：`768 × 1024`
   - **💻 桌面端 (Desktop)**：`1440 × 900`
2. 当你切换到 **平板** 或 **桌面** 视口后，在右侧属性面板修改某个组件的**宽度、高度、内外边距、背景色、渐变、圆角或边框**时，这些修改只会记录在当前断点下，不会破坏手机端的默认排版。
3. 应用在真机或浏览器运行时，会根据当前屏幕宽度自动切换到对应断点的样式；若某属性在平板/桌面端未单独设置，则自动继承手机端的默认属性。

## 四、四象限属性检查器与主题色彩系统

在画布中选中任意组件后，右侧 **「属性检查器」** 分为四个标签象限：

### 1. 四大属性象限

- **外观 (Appearance)**：
  - **尺寸**：宽度、高度（支持输入具体像素值、百分比或设为自适应/撑满）。
  - **边距**：内边距 (`Padding`) 与外边距 (`Margin`)，支持上下左右四方向独立设置。
  - **装饰**：背景颜色、线性/径向渐变色、边框粗细与颜色、四个角独立的圆角半径、阴影效果与透明度 (`Opacity`)。
- **内容 (Content)**：
  - 配置组件特有的业务属性（如文本内容、字号、输入框占位符、开关默认状态）。
  - **三合一媒体选择器**：点击图标或图片属性时，可在弹窗中直接选择 **Material 图标、Cupertino 图标、网络图片 URL 或本地项目资源图片**。
  - **数据绑定**：点击属性右侧的绑定按钮（或直接输入 `{{变量名}}`），即可将组件内容与动态状态变量关联。
- **事件 (Events)**：
  - 为组件绑定交互动作，如 **点击 (`onTap`)、双击、长按、鼠标悬浮 (`onHover`)、值改变 (`onChanged`)、提交 (`onSubmitted`)、下拉刷新 (`onRefresh`)** 等。
- **布局 (Layout)**：
  - 配置弹性权重 (`flex`)、主轴对齐 (`mainAxisAlignment`)、交叉轴对齐 (`crossAxisAlignment`)、子元素间距 (`spacing`) 以及条件显隐 (`visible`)。

### 2. 10 大内置语义色彩 Token（自动适配亮/暗黑模式）

在设置组件颜色时，除了直接输入十六进制色值（如 `#FF6B00`），**强烈推荐使用平台内置的 10 大语义色彩 Token**。使用语义色后，当应用调用 `切换主题模式()` 切换到暗黑模式时，所有界面颜色会自动平滑切换，无需手动写两套样式：

| 色彩名称 | 代码与属性写法 | 浅色模式默认色 | 深色模式默认色 | 推荐用途 |
| :--- | :--- | :---: | :---: | :--- |
| **主品牌色** | `QcColor.primary` | `#2563EB` | `#3B82F6` | 主操作按钮、激活态图标、高亮边框、开关选中色 |
| **页面底色** | `QcColor.background` | `#F8FAFC` | `#0F172A` | 页面脚手架整体大背景 |
| **容器表面色** | `QcColor.surface` | `#FFFFFF` | `#1E293B` | 卡片底色、弹窗背景、顶部/底部导航栏背景 |
| **主要文字色** | `QcColor.textMain` | `#0F172A` | `#F8FAFC` | 页面大标题、正文内容、重要数值 |
| **次要文字色** | `QcColor.textSub` | `#64748B` | `#94A3B8` | 副标题、辅助说明、占位提示词、时间戳 |
| **分割边框色** | `QcColor.border` | `#E2E8F0` | `#334155` | 输入框边框、列表分割线、卡片外框 |
| **禁用状态色** | `QcColor.disable` | `#CBD5E1` | `#475569` | 不可点击按钮背景、禁用文字与置灰图标 |
| **成功状态色** | `QcColor.success` | `#10B981` | `#34D399` | 审核通过、支付成功、正向增长徽标 |
| **警告状态色** | `QcColor.warning` | `#F59E0B` | `#FBBF24` | 待处理提醒、库存预警、中风险提示 |
| **危险状态色** | `QcColor.danger` | `#EF4444` | `#F87171` | 删除按钮、表单报错文字、异常警告 |
